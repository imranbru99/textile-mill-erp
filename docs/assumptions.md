# Assumptions

- Adhikar is not on Packagist. Roles and permissions use `permissions`, `roles`, `role_permission` and `user_role` with the same `module.resource.action` names. `MillPolicy` is the adapter.
- `imrandevbd/tarikh` exposes Gregorian arithmetic only. The Bangladesh revised Bangla calendar (Pohela Boishakh = 14 April) lives in `App\Support\BanglaCalendar` and uses Tarikh to parse the date.
- `imrandevbd/laravel-filament-master` targets Filament v3 and is not auto-discovered. Resources are Filament v4 classes generated by `scripts/emit_mill.py`.
- Local demo uses SQLite. Production and Docker use MySQL 8. MariaDB on this machine refused the `dev` user.
- The portal shell from `laravel-admin-panel` is mounted at `/desk` so it does not collide with Filament at `/admin`.
- Excel export uses OpenSpout because PhpSpreadsheet does not support PHP 8.5.
- AQL plans are the mill QC subset of ISO 2859-1 Level II normal (AQL 1.0, 1.5, 2.5, 4.0), not a photocopy of every code letter in the standard.
- AI features call `laravel-ai-hub` only, store the prompt and response, and return nothing useful when `MILL_AI_ENABLED` is false or the provider key is missing.
- SMS is a `SmsGateway` adapter that logs until a Bangladesh gateway is bound.
- Valuation default is weighted average. FIFO is selected on the company.
- Ordinary hours are 8 per day and 48 per week. Overtime is 2× basic / (26 × 8). Weekly hours above 60 block the payroll line.
- VAT default is 15%. Export invoices in the demo are zero-rated.
- Brand name comes from `companies.brand_name` and `MILL_BRAND`.
